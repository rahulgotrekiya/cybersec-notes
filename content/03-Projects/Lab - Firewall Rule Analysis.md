# Lab: Firewall Rule Analysis and Network Topology Design

> 🔬 **Lab Practical** — CSF & NS Practical 4 | Est. time: 3 hrs

---

## 🎯 Objective
Analyse firewall rules for misconfigurations and design a secure network topology.

## 📝 Procedure
1. Review provided firewall rule set
2. Identify 3 misconfigurations with justification
3. Rewrite corrected rules
4. Design network topology with DMZ using draw.io
5. Justify IDS placement in the topology

## 💭 Observation Questions
1. What is the purpose of a DMZ? Why should a web server not sit on the internal LAN?
2. A rule says "Allow TCP ANY ANY port 443." Why is this dangerous even though 443 is HTTPS?
